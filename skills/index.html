Введение в agent skills

Как один раз научить Claude Code делать повторяющуюся работу и больше не вставлять одни и те же инструкции в каждый запрос.

Skill — это папка с файлом SKILL.md. В нём коротко сказано, когда skill нужен, и подробно — что делать. Claude Code при старте читает только имена и описания. Полный текст подключается, когда запрос совпадает по смыслу.

Шесть уроков ниже идут в том же порядке, что и курс. Текст написан по-русски своими словами: те же темы и примеры, плюс блоки «Пояснение» там, где в оригинале мало деталей или формулировка уже разошлась с документацией Claude Code. Видео — те же ролики с YouTube.
