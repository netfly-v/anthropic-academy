Пять шагов

Видео, около 5 минут.

Смотреть урок на Skilljar Accessing the API · 5:18

Пользователь нажимает «отправить» в вашем чате. Дальше цепочка всегда одна и та же, даже если интерфейс разный.

  1. Браузер отправляет текст на ваш сервер.
  2. Сервер вызывает Anthropic API: официальным SDK или обычным HTTP.
  3. Модель обрабатывает запрос.
  4. API возвращает серверу структурированный ответ.
  5. Сервер отдаёт текст обратно в интерфейс.

SDK есть для Python, TypeScript, JavaScript, Go и Ruby. Смысл полей от языка не меняется. В запросе нужны ключ API, имя модели, список сообщений и max_tokens — потолок длины ответа.

Пояснение

Ключ не должен жить в браузере. Страница, которую видит пользователь, ходит на ваш сервер. Уже сервер хранит ключ и говорит с Anthropic. Иначе любой, кто открыл сайт, может потратить ваш счёт.

Внутри модели запрос проходит четыре грубых этапа: текст режется на токены, каждый токен становится числовым вектором, соседние слова уточняют смысл, затем модель выбирает следующий кусок текста. Вам не нужно считать эти векторы. Нужно помнить, что вы платите за входные и выходные токены, а не за «один вопрос».

Что приходит назад

Ответ — не просто строка. В нём есть сгенерированный текст, причина остановки и счётчик токенов. В интерфейс обычно уходит только текст. Остальное нужно вам: понять, оборвался ли ответ по лимиту, и сколько стоил ход.
