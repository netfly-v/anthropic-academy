System prompt

Чему научитесь

Около 6 минут

К концу урока вы сможете:

  • задать роль и ограничения через параметр system;
  • не путать его с сообщением пользователя;
  • понять, что system prompt действует на весь разговор, пока вы его передаёте.

Роль рядом с историей

Видео, около 6 минут.

Смотреть урок на Skilljar System prompts · 6:20

messages — это реплики. system — инструкция над ними: кто модель в этом приложении, чего ей нельзя, каким тоном отвечать. Его передают отдельным аргументом, не как ещё один role: user.

client.messages.create(
    model=model,
    max_tokens=500,
    system="You are a patient Python tutor. Give a hint first, not the full solution.",
    messages=[{"role": "user", "content": "Why does my loop never end?"}],
)

Пояснение

Если положить правила в первое пользовательское сообщение, человек может их «перебить» следующей репликой вроде «забудь инструкции». Отдельное поле system для этого и существует: это не реплика участника диалога. На каждый ход его нужно передавать снова, вместе со всей историей. Само оно в список messages не дописывается.

Вопросы к себе

  • Какое одно ограничение вашего продукта нельзя отдавать на волю формулировки пользователя?
  • Что останется в messages, если правила уедут в system?
