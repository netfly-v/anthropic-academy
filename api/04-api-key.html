Ключ API

Чему научитесь

Около 5 минут

К концу урока вы сможете:

  • создать ключ в консоли Anthropic;
  • подставить его в программу через переменную окружения;
  • не закоммитить секрет в репозиторий.

Где его взять

Видео про ключ и окружение.

Смотреть урок на Skilljar Getting an API key · видео

Ключ создаётся в консоли Anthropic, на console.anthropic.com. Это длинная строка. Она подтверждает, что запрос ваш, и списание идёт с вашего счёта. Показать её в чате, в скриншоте или в git — то же самое, что отдать пароль.

В курсе ключ кладут в файл .env рядом с ноутбуком и читают пакетом python-dotenv. SDK сам смотрит переменную ANTHROPIC_API_KEY, если вы не передали ключ в коде.

ANTHROPIC_API_KEY=sk-ant-...
from dotenv import load_dotenv
from anthropic import Anthropic

load_dotenv()
client = Anthropic()

Файл .env добавляют в .gitignore. В репозиторий кладут пример без секрета, например .env.example с пустым значением, чтобы коллега понял, какое имя переменной нужно.

Пояснение

Если ключ уже попал в коммит, удалить строку в следующем коммите недостаточно: она остаётся в истории. Ключ надо отозвать в консоли и выпустить новый. Локальный ноутбук для учёбы — нормальное место для .env. Публичный сайт — нет: там ключ только на сервере.

Вопросы к себе

  • Есть ли у вас уже .gitignore, в котором перечислен .env?
  • Кто ещё должен иметь возможность звать API от вашего имени, и заведёте ли вы им отдельный ключ?
