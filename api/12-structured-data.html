Текст, который читает код

Видео, около 6 минут.

Смотреть урок на Skilljar Structured data · 5:59

Программе редко нужен абзац. Ей нужны поля: имя, дата, сумма. Самый прямой приём этого урока — прямо попросить JSON и распарсить строку.

import json

reply = client.messages.create(
    model=model,
    max_tokens=300,
    temperature=0,
    messages=[{
        "role": "user",
        "content": "Return only JSON with keys name, date, amount. Text: Anna paid 40 EUR on 2 March.",
    }],
)
data = json.loads(reply.content[0].text)

Низкая temperature здесь уместна: формат важнее разнообразия. Если модель добавит фразу до или после JSON, json.loads упадёт.

Пояснение

Просьба «верни только JSON» — договорённость, не гарантия схемы. Для жёстких полей в следующем блоке курса используют tool use: модель вызывает инструмент с аргументами по схеме, и лишний текст не смешивается с данными. Пока достаточно уметь попросить JSON, разобрать его и поймать ошибку парсинга, а не показывать пользователю traceback.

Вопросы к себе
