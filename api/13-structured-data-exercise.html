Упражнение: поля из текста

Чему научитесь

Около 5 минут

К концу урока вы сможете:

  • достать из свободного текста имя, дату и сумму;
  • проверить, что в JSON нет выдуманных полей;
  • обработать ответ, который не разобрался как JSON.

Три поля

Упражнение, около 5 минут.

Смотреть урок на Skilljar Structured data exercise · 4:57

Возьмите фразу вроде «Мария перевела 120 евро 4 апреля» и попросите только JSON с ключами name, date, amount. Сверьте глазами: имя не переврали, сумма не стала другой валютой, дата не уехала на другой день.

text = "Maria transferred 120 EUR on 4 April."
# Ask for JSON only, temperature 0, then json.loads.
# If a key is missing in the source sentence, the value should be null.

Повторите на фразе, где суммы нет. Хороший ответ ставит amount в null, а не выдумывает число.

Пояснение

Оборачивайте json.loads в try. Ветка ошибки — это «не смог разобрать», а не падение ноутбука. Если такое случается часто, сузьте инструкцию или переходите к схеме через tool use в следующем разделе курса. Опрос удовлетворённости в середине оригинального блока мы пропускаем: в нём нет нового материала.

Дальше

Проверьте блок коротким экзаменом. Следующий большой раздел оригинала — оценка промптов, его ещё не переводили.
