Видео и текст урока.

Смотреть урок на Skilljar Claude Code setup · 1:33

Claude Code — помощник по программированию, который работает прямо в командной строке. Представьте, что Claude доступен у вас в терминале и готов помочь с любой задачей по коду, над которой вы работаете.

Что умеет Claude Code

У Claude Code есть полный набор инструментов для рабочего процесса разработки:

  • Работа с файлами — поиск, чтение и редактирование файлов проекта;
  • Доступ к терминалу — запуск команд прямо из разговора;
  • Доступ к вебу — поиск документации, получение примеров кода и другое;
  • Поддержка MCP-серверов — новые инструменты через подключение MCP-серверов.

Интеграция с MCP особенно сильна: расширять возможности Claude Code можно специализированными инструментами для баз данных, API и любых других сервисов, с которыми вы работаете.

Claude Code работает на macOS, Windows WSL и Linux, так что им можно пользоваться в любой среде разработки.

Установка

Чтобы установить Claude Code, достаточно трёх шагов:

  • установите Node.js с nodejs.org/en/download (проверить, есть ли он уже, можно командой npm help в терминале);
  • установите Claude Code командой npm install -g @anthropic-ai/claude-code;
  • запустите и войдите в аккаунт: выполните claude в терминале.

При первом запуске команды claude она попросит войти в аккаунт Anthropic. Полное руководство по установке есть на docs.anthropic.com, если нужны подробности.

После установки Claude будет доступен прямо в терминале и готов помочь с любым проектом или задачей по коду.

Пояснение

  • Рекомендуемый способ установки сейчас — нативный установщик, Node.js для него не нужен: на macOS, Linux и WSL — curl -fsSL https://claude.ai/install.sh | bash, в Windows PowerShell — irm https://claude.ai/install.ps1 | iex. Есть также Homebrew и WinGet. Способ из курса (npm install -g @anthropic-ai/claude-code) по-прежнему поддерживается, но требует Node.js 22 или новее.
  • Windows поддерживается нативно, WSL больше не обязателен.
  • Аккаунт. Для входа нужен план Pro, Max, Team, Enterprise или аккаунт Claude Console; бесплатный план claude.ai доступа к Claude Code не даёт. Можно работать и через облачных провайдеров (Amazon Bedrock, Google Cloud, Microsoft Foundry). Проверить установку — claude --version, диагностика — claude doctor.
  • Документация переехала. Руководство по Claude Code теперь на code.claude.com/docs, а не на docs.anthropic.com.
