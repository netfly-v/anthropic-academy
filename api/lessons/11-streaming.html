Смотреть урок на Skilljar Response streaming · 8:23

Обычный вызов молчит, пока модель не закончит. Для длинного ответа интерфейс кажется зависшим. Поток присылает события по ходу. Текст из них можно сразу писать на экран.

with client.messages.stream(
    model=model,
    max_tokens=1000,
    messages=[{"role": "user", "content": "Explain photosynthesis in a short paragraph."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

Пояснение

Поток не делает генерацию короче и не снижает счёт за выходные токены. Он только раньше показывает то, что и так было бы сгенерировано. В конце у потока есть собранное сообщение: его удобно сохранить в историю messages, чтобы следующий ход не собирал строку из кусков вручную. Если stop_reason равен max_tokens, пользователь увидел обрыв, даже если куски приходили плавно.
