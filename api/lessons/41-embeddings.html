Смотреть урок на Skilljar Text embeddings · 4:02

После разбиения документа на фрагменты следующий шаг конвейера RAG — найти фрагменты, которые подходят к вопросу пользователя. По сути, это задача поиска: нужно просмотреть все фрагменты и определить те, что связаны с вопросом.

Семантический поиск

Самый распространённый способ найти подходящие фрагменты — семантический поиск. В отличие от поиска по ключевым словам, который ищет точные совпадения слов, семантический поиск использует эмбеддинги текста, чтобы понять смысл и контекст и вопроса, и каждого фрагмента.

Эмбеддинги текста

Эмбеддинг текста — числовое представление смысла, заключённого в тексте. Можно думать о нём как о переводе слов и предложений в форму, с которой компьютер может работать математически.

Процесс такой:

  • текст подаётся на вход модели эмбеддингов;
  • модель выдаёт длинный список чисел — эмбеддинг;
  • каждое число лежит в диапазоне от −1 до +1;
  • эти числа отражают разные свойства или признаки входного текста.

Что означают числа

Каждое число в эмбеддинге — по сути «оценка» какого-то свойства текста. Но есть важная оговорка: мы не знаем точно, что означает каждое число.

Полезно представлять, что одно число означает «насколько текст радостный», а другое — «насколько он про океаны», но это лишь условные примеры. Настоящий смысл каждого измерения модель выучивает при обучении, и человек не может его напрямую интерпретировать.

VoyageAI для эмбеддингов

Anthropic сейчас не предоставляет генерацию эмбеддингов, поэтому рекомендуемый провайдер — VoyageAI. Нужно:

  • зарегистрировать отдельный аккаунт VoyageAI;
  • получить API-ключ (начать можно бесплатно);
  • добавить ключ в переменные окружения.

В файл .env добавьте:

VOYAGE_API_KEY="your_key_here"

Реализация

Сначала установите библиотеку VoyageAI:

%pip install voyageai

Затем настройте клиент и напишите функцию генерации эмбеддингов:

from dotenv import load_dotenv
import voyageai

load_dotenv()
client = voyageai.Client()

def generate_embedding(text, model="voyage-3-large", input_type="query"):
    result = client.embed([text], model=model, input_type=input_type)
    return result.embeddings[0]

Если запустить функцию на фрагменте текста, она вернёт список чисел с плавающей точкой — эмбеддинг. Процесс быстрый и простой; настоящая сложность — понять, как эффективно использовать эмбеддинги в конвейере RAG для поиска самого подходящего содержимого.

Следующий шаг — научиться сравнивать эмбеддинги, чтобы определять, какие фрагменты больше всего похожи на вопрос пользователя. Это и есть основа семантического поиска.

Пояснение

  • Voyage AI сейчас. По документации Anthropic, своей модели эмбеддингов у Anthropic по-прежнему нет, а Voyage AI теперь часть MongoDB: ключ создают в MongoDB Atlas (раздел AI Model APIs), библиотека voyageai нужна версии 0.3.7+. Текущее поколение моделей — voyage-4-large, voyage-4, voyage-4-lite; voyage-3-large из урока — предыдущее поколение. Есть и специализированные модели: для кода (voyage-code-4), финансов, права.
  • input_type важен. Документация советует для поиска всегда указывать, что эмбеддится: "query" для вопроса пользователя и "document" для фрагментов. Функция урока по умолчанию ставит "query" и для фрагментов — при индексации их лучше эмбеддить с input_type="document".
  • Числа «от −1 до +1» — упрощение. Эмбеддинги Voyage нормализованы к длине 1, поэтому каждое число по модулю не больше 1; главное — не отдельные числа, а направление вектора целиком.
  • Пакетная обработка. client.embed принимает список текстов, так что фрагменты выгоднее отправлять пачкой, а не по одному (в уроке «Реализация RAG» функцию так и доработают).
