Что должно получиться

Маленький чат в ячейке Jupyter. Пока ячейка запущена, она снова и снова спрашивает текст.

  1. Пустой список messages.
  2. Бесконечный цикл while True.
  3. Внутри цикла встроенный input кладёт строку в переменную.
  4. add_user_message добавляет её в список.
  5. chat отправляет список и возвращает текст.
  6. add_assistant_message кладёт ответ в тот же список.
  7. Ответ печатают между строками ---, чтобы было видно, что это ответ модели.
  8. Цикл возвращается к input.

В ролике проверка такая: «what's one plus one», затем «add to that answer». Второй ответ должен опираться на первый и говорить про четыре. Остановить цикл — кнопка interrupt в ноутбуке и Escape.

messages = []
while True:
    user_input = input()
    add_user_message(messages, user_input)
    answer = chat(messages)
    add_assistant_message(messages, answer)
    print("---")
    print(answer)
    print("---")

Пояснение

Ролик предлагает сначала поставить паузу и собрать цикл по комментариям в ячейке. Решение выше повторяет те же вызовы, которые он потом дописывает: add user, chat, add assistant, print.
