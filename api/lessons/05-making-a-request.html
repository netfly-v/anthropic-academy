Три поля

Видео, около 6 минут.

Смотреть урок на Skilljar Making a request · 6:02

В ноутбуке ставят SDK и чтение .env. Дальше один вызов.

message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1000,
    messages=[
        {"role": "user", "content": "What is quantum computing? Answer in one sentence."}
    ],
)
  • model — конкретное имя модели, не слово «Sonnet».
  • max_tokens — страховка. При 1000 модель остановится, даже если хотела продолжить. Она не старается дописать ровно до лимита.
  • messages — история. У каждого элемента есть role (user или assistant) и content.

Объект ответа большой. Текст обычно здесь:

print(message.content[0].text)

Пояснение

Имя модели в примере — ориентир. В курсе на Skilljar может стоять более старый идентификатор. Берите ту версию, которую выбрали в уроке про семейства, и держите её в одной переменной ноутбука. Если ответ оборвался на полуслове, смотрите stop_reason: значение max_tokens значит, что упёрлись в потолок, а не в смысл.

Вопросы к себе

  • Какой max_tokens вы поставите для одного предложения и какой для длинного разбора?
  • Что вы напечатаете в ноутбуке, если нужен только абзац, а не весь объект?
