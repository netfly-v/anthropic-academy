Смотреть урок на Skilljar Making a request · 6:02

Сделать первый запрос к Anthropic API несложно, если понимать базовую настройку и структуру. Эта инструкция проходит по основным шагам, чтобы Claude начал отвечать на ваши промпты из Python.

Настройка окружения

Прежде чем вызывать API, нужно поставить пакеты и безопасно настроить API-ключ.

Сначала установите зависимости в Jupyter-ноутбуке:

%pip install anthropic python-dotenv

Затем создайте файл .env в той же папке, что и ноутбук, и сохраните в нём ключ:

ANTHROPIC_API_KEY="your-api-key-here"

Так ключ не попадает в код, и его не получится случайно закоммитить в систему контроля версий. Всегда добавляйте .env в .gitignore.

Загрузите переменные окружения и создайте клиент API:

from dotenv import load_dotenv
load_dotenv()

from anthropic import Anthropic

client = Anthropic()
model = "claude-sonnet-4-0"

Пояснение

  • Почему Anthropic() без аргументов. load_dotenv() кладёт строки из .env в переменные окружения, а SDK сам читает оттуда ANTHROPIC_API_KEY. Передавать ключ явно (Anthropic(api_key=...)) не нужно и небезопасно.
  • Модель курса снята. claude-sonnet-4-0 (полный ID claude-sonnet-4-20250514) снята с поддержки 15 июня 2026 года: код из урока как есть завершится ошибкой. Рекомендованная замена по странице Model deprecations — claude-sonnet-5-5.
  • Какую модель ставить в код курса. Удобнее всего model = "claude-sonnet-4-6": она активна как минимум до 17 февраля 2027, без параметра thinking отвечает без блока размышлений (поэтому message.content[0].text из курса работает как есть) и ещё принимает temperature (урок 10). Не примет она только prefill (уроки 12–13): его поддерживают лишь модели линейки 4.5 и старше, например claude-opus-4-5-20251101 — активна не раньше чем до 24 ноября 2026.
  • А как же claude-sonnet-5-5? Для новых приложений берите её. Но код курса на ней ведёт себя иначе: адаптивное мышление включено по умолчанию, и ответ может начинаться с блока thinking — тогда content[0] окажется не текстом. Надёжнее доставать текст по типу блока: next(b.text for b in message.content if b.type == "text"). Нестандартная temperature и prefill на ней дают ошибку 400.
  • Версия SDK. %pip install anthropic сейчас ставит SDK 1.x. В нём у messages.create() больше нет параметров temperature, top_p, top_k — передача даёт TypeError ещё до запроса. Это важно для урока 10: как обойти, разобрано там.

Функция create

Основа запросов к API — функция client.messages.create(). У неё три обязательных параметра:

  • model — имя модели Claude, которую вы хотите использовать;
  • max_tokens — страховочный лимит длины ответа (не целевая длина);
  • messages — история разговора, которую вы отправляете Claude.

Параметр max_tokens работает как предохранитель. Если поставить 1000, Claude остановится после 1000 токенов, даже если хотел сказать больше. Claude не старается дотянуть до этого лимита: он пишет столько, сколько считает нужным, и останавливается, только если упрётся в максимум.

Что такое messages

Сообщения — это переписка между вами и Claude, как в чате. Сообщения бывают двух типов:

  • сообщения пользователя (user) — то, что вы отправляете Claude (пишут люди);
  • сообщения ассистента (assistant) — ответы, которые сгенерировал Claude.

Каждое сообщение — словарь с ключами role ("user" или "assistant") и content (сам текст).

Первый запрос

Полный пример запроса к Claude:

message = client.messages.create(
    model=model,
    max_tokens=1000,
    messages=[
        {
            "role": "user",
            "content": "What is quantum computing? Answer in one sentence"
        }
    ]
)

Когда вы запустите этот код, Claude обработает запрос и вернёт объект ответа: сгенерированный текст плюс метаданные о запросе.

Как достать ответ

В объекте ответа много информации, но обычно нужен только сгенерированный текст. Он лежит здесь:

message.content[0].text

Получится чистый читаемый текст вроде: «Quantum computing is a type of computation that leverages quantum mechanics principles like superposition and entanglement to process information using quantum bits (qubits), potentially solving certain complex problems exponentially faster than classical computers.»

Пояснение

Почему content[0], а не просто content: content — это список блоков. В простом ответе там один блок {"type": "text", "text": "..."}, но позже, с инструментами и thinking, блоков будет несколько и разных типов. Кроме content, в ответе полезны:

  • message.stop_reason — почему генерация остановилась ("end_turn", "max_tokens"…);
  • message.usage.input_tokens и message.usage.output_tokens — сколько токенов ушло, от этого зависит цена;
  • message.role — всегда "assistant"; message.model — какая модель ответила.

С этими основами можно экспериментировать с разными промптами и строить более сложные сценарии работы с Claude.
