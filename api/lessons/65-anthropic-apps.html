Видео и текст урока.

Смотреть урок на Skilljar Anthropic apps · 0:43

В этом модуле мы разберём два мощных приложения, созданных Anthropic: Claude Code и Computer Use. Это не просто полезные инструменты сами по себе — это отличные примеры AI-агентов в действии. Разобравшись, как они устроены, вы получите прочную основу, чтобы позже строить собственных агентов.

Наш план

Мы пойдём по шагам, постепенно углубляя понимание:

  • Claude Code — начнём с этого агентного помощника по программированию, который работает в терминале;
  • Computer Use — разберём набор инструментов, позволяющий Claude работать с настольными приложениями;
  • Агенты — поймём, что делает эти приложения успешными агентами.

Claude Code

Claude Code — помощник по программированию в терминале, который помогает с самыми разными задачами разработки. Представьте, что Claude доступен прямо в командной строке и готов:

  • редактировать файлы и исправлять ошибки;
  • отвечать на вопросы по коду;
  • помогать с рабочими процессами разработки.

Мы пройдём весь процесс установки, а затем поработаем с Claude Code на небольшом учебном проекте, чтобы вы увидели, как именно он действует на практике.

Computer Use

Computer Use заметно расширяет возможности Claude. Это набор инструментов, которые позволяют Claude работать в полноценной среде настольного компьютера. То есть Claude может:

  • открывать сайты и пользоваться интернетом;
  • работать с настольными приложениями;
  • выполнять задачи, для которых нужно ориентироваться в графическом интерфейсе.

По сравнению с чисто текстовым взаимодействием это резко расширяет круг возможного.

Почему это важно для агентов

И Claude Code, и Computer Use — отличные учебные примеры для понимания агентов. Они показывают ключевые принципы, благодаря которым агенты эффективны:

  • подключение и использование инструментов;
  • выполнение задач в несколько шагов;
  • взаимодействие со средой;
  • самостоятельное решение задач.

Изучив эти реальные реализации, вы поймёте, что делает Claude Code и Computer Use успешными, и это пригодится, когда вы будете разрабатывать собственных агентов.

Пояснение

  • Отдельного урока про Computer Use в курсе сейчас нет. В оглавлении раздела после этого вступления идут только три урока о Claude Code, а затем — раздел об агентах. Поэтому коротко о Computer Use по актуальной документации.
  • Как устроен Computer Use. Это клиентский набор инструментов Anthropic: Claude получает скриншоты и отдаёт команды мыши и клавиатуры (screenshot, left_click, type, zoom и другие), а выполняет их ваше приложение в среде, которую вы контролируете. Это тот же цикл tool use, что в блоке «Инструменты».
  • Версии инструмента. В Claude API модели Claude 5.5 и новее принимают только набор {"type": "computer_toolset_20260801"} — без бета-заголовка; на старые версии (computer_20251124, computer_20250124) они возвращают ошибку. Модели Claude 4.x (Opus 4.7, Opus 4.6, Sonnet 4.6, Opus 4.5) работают только с computer_20251124, и ему нужен бета-заголовок. На других платформах (Bedrock, Foundry) пока доступны только бета-версии.
  • Безопасность. Документация советует запускать Computer Use в отдельной виртуальной машине или контейнере с минимальными правами, не давать доступ к чувствительным данным (например, паролям), ограничивать интернет списком разрешённых доменов и просить человека подтверждать важные действия.
