Смотреть урок на Skilljar System prompts exercise · 1:25

Задача

Короткое упражнение на system prompt. В ноутбуке Claude просят написать функцию на Python, которая проверяет строку на повторяющиеся символы. Если запустить ячейку и напечатать ответ, кода окажется очень много: немного самого кода, но ещё и много объяснений и комментариев.

Нужно сократить объём сгенерированного и получить максимально лаконичную реализацию функции. Для этого напишите system prompt и передайте его в вызов chat. Промпт должен назначить Claude роль и побудить отвечать как можно лаконичнее.

Здесь в ролике предлагают поставить видео на паузу и попробовать самим.

Решение

В вызов chat передают system prompt, который назначает Claude роль, располагающую к очень лаконичному коду:

answer = chat(
    messages,
    system="You are a Python engineer who writes very concise code."
)

Ответ стал гораздо ближе к нужному: код проверки уникальности очень короткий — намного короче того, что был в первый раз.

Если с первого раза не получилось — ничего страшного: дальше в курсе будет много других упражнений.

Пояснение

Код в ролике целиком не показан; выше — вызов функции chat(messages, system=...) из прошлого урока с той самой строкой промпта. Обратите внимание на приём: роль («Python engineer») плюс явное требование к форме ответа («very concise code»). Сам вопрос пользователя при этом не меняется — меняется только поведение модели.
