Ключ API

Чему научитесь

Текстовый урок, около 2 минут

К концу урока вы сможете:

  • открыть консоль Anthropic и найти раздел ключей;
  • создать ключ в workspace Default с понятным именем;
  • сохранить ключ, пока окно с ним ещё открыто.

В следующем видео мы сделаем запрос к Anthropic API. Для этого понадобится секретный API-ключ. Эта инструкция показывает, как его создать.

Шаг 1. Откройте консоль Anthropic API

В браузере перейдите на https://console.anthropic.com/ и войдите в аккаунт Anthropic. Вы увидите примерно такую страницу:

Пояснение

Консоль переехала: сейчас она открывается по адресу platform.claude.com (старый адрес перенаправляет туда). Интерфейс может выглядеть иначе, чем на скриншотах, но шаги те же.

Шаг 2. Нажмите Get API Keys

Кнопка находится в правом верхнем углу главной панели.

Шаг 3. Нажмите Create Key

Найдите кнопку «Create Key» в правом верхнем углу страницы и нажмите её.

Шаг 4. Выберите workspace и задайте имя ключа

Создайте ключ в workspace «Default» и введите имя ключа. Имя нужно, чтобы потом отличать свои ключи друг от друга. Назовём его «Anthropic Course».

Шаг 5. Скопируйте ключ

Ключ появится во всплывающем окне. Скопируйте его и сохраните — он понадобится в следующем видео. Ключ показывается только один раз, так что обязательно скопируйте его!

Если случайно закрыли окно, удалите старый ключ и создайте новый.

Пояснение

  • Оплата API отдельная. Подписка Claude Pro или Max на claude.ai не даёт кредитов для API. Запросы оплачиваются по токенам в консоли (Billing), и без пополненного баланса ключ будет получать ошибки.
  • Ключ — как пароль. Не вставляйте его в код и не коммитьте в git. Куда его положить, показывает следующий урок: в файл .env, откуда SDK читает переменную ANTHROPIC_API_KEY.
  • Workspace — группа ключей внутри организации со своими лимитами и расходами. Для курса хватает «Default».

Дальше

С ключом на руках можно настроить ноутбук и сделать первый запрос.
