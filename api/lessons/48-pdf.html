Видео и текст урока.

Смотреть урок на Skilljar PDF support · 1:29

Claude умеет читать и анализировать PDF-файлы напрямую, и это делает его мощным инструментом для обработки документов. Это работает похоже на обработку изображений, но с несколькими ключевыми отличиями в коде.

Настройка обработки PDF

Чтобы обработать PDF, используется почти тот же код, что и для изображений. Главные отличия — в указании типа файла и в именах переменных для ясности.

Вот как переделать код обработки изображений для PDF:

with open("earth.pdf", "rb") as f:
    file_bytes = base64.standard_b64encode(f.read()).decode("utf-8")

messages = []

add_user_message(
    messages,
    [
        {
            "type": "document",
            "source": {
                "type": "base64",
                "media_type": "application/pdf",
                "data": file_bytes,
            },
        },
        {"type": "text", "text": "Summarize the document in one sentence"},
    ],
)

chat(messages)

Что меняется по сравнению с изображениями

Переделывая код для PDF, обновите:

  • расширение файла: .png → .pdf;
  • имя переменной: image_bytes → file_bytes (для ясности);
  • тип блока: "image" → "document";
  • тип данных: "image/png" → "application/pdf".

Что Claude извлекает из PDF

Обработка PDF в Claude — больше, чем извлечение текста. Claude анализирует и понимает:

  • текст по всему документу;
  • изображения и графики внутри PDF;
  • таблицы и связи между их данными;
  • структуру и оформление документа.

По сути, Claude становится универсальным решением для извлечения любой информации из PDF: нужны ли вам краткие пересказы, анализ данных или извлечение конкретного содержимого.

На примере выше Claude успешно обрабатывает статью Википедии о Земле, сохранённую в PDF, — и понимает и пересказывает сложное содержимое одним предложением.

Пояснение

  • Лимиты (по документации на октябрь 2026): размер запроса — до 32 МБ, до 600 страниц (100 — если окно контекста запроса меньше миллиона токенов). PDF без пароля и шифрования.
  • Как это работает. Каждая страница передаётся модели и как извлечённый текст, и как изображение страницы — поэтому Claude видит графики и таблицы. Отсюда и стоимость: страница стоит и текстовые токены, и токены изображения.
  • Другие источники. Кроме base64, PDF можно передать ссылкой ({"type": "url", "url": ...}) или через Files API ({"type": "file", "file_id": ...}) — для больших файлов это предпочтительнее.
