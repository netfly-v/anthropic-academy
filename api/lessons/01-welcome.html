Карта курса

Видео, 2 минуты 14 секунд. На странице Skilljar нет текста, только ролик.

Смотреть урок на Skilljar Welcome to the course · 2:14

Курс ведёт сотрудник Anthropic и сразу раскладывает дорожку. Сначала коротко про сами модели. Потом доступ к ним через официальный API. Затем промпты: сначала как их оценивать, потом приёмы, которыми их пишут. Дальше tool use — как расширить Claude внешними действиями. Потом retrieval augmented generation: как подкладывать в запрос нужный кусок ваших данных. Затем Model Context Protocol, чтобы подключать новые сервисы. После этого два агента Anthropic, Claude Code и Computer Use, и в конце — workflows и agents для задач сложнее одного запроса.

Коротко

  • Сначала модели и API, потом промпты, tools, RAG, MCP, готовые агенты и свои сценарии.
  • Нужен базовый Python и среда, в которой запускаются ноутбуки: почти весь код курса пишется и выполняется там.
  • Нужен аккаунт Anthropic или ключ API. Как его получить, расскажут в следующих уроках, не в этом.

Пояснение

Этот урок — только карта. Кода здесь нет. Следующий блок оригинала, Accessing Claude with the API, начинается с того, как устроен запрос и где взять ключ. Его русский конспект появится отдельно. JSON в требованиях курса нужен потому, что и запрос, и ответ API — это объекты: роль сообщения, текст, лимит токенов, usage.

Что подготовить

  • Понимать Python на уровне функций, списков и словарей. Курс не учит язык с нуля.
  • Иметь среду для ноутбуков: Jupyter, VS Code или то, чем вы уже пользуетесь. Команды установки пакетов в курсе идут внутри ноутбука.
  • Иметь доступ к API. Без ключа примеры не отработают, но смотреть устройство запроса можно и до этого.

Как проходить

Ролик даёт четыре практических совета, потому что темп высокий.

  1. Пишите код вместе с видео. Просмотр чужого набора ячеек почти ничего не закрепляет.
  2. Ускоряйте воспроизведение и возвращайтесь к тем роликам, которые оказались плотными.
  3. Меняйте ноутбуки под свою задачу: добавьте поле, другой пример, другой лимит. Так приём становится вашим.
  4. Если застряли, спросите Claude. Он годится и чтобы починить ошибку в ячейке, и чтобы пересказать место, которое прозвучало быстро.

Пояснение

Ноутбук здесь — файл с ячейками кода и текста, который выполняется по частям. Для API это удобно: один запрос, сразу ответ, следующая ячейка дописывает диалог. Отдельный сервис поднимать не нужно, пока вы учитесь форме messages.
