  • встроить инспектор в цикл разработки.

Видео и текст урока.

Смотреть урок на Skilljar The server inspector · 3:52

Создавая MCP-серверы, нужен способ проверять их работу без подключения к полному приложению. В Python MCP SDK есть встроенный инспектор в браузере, с которым можно отлаживать и тестировать сервер в реальном времени.

Запуск инспектора

Сначала убедитесь, что окружение Python активировано (точная команда — в README проекта). Затем запустите инспектор:

mcp dev mcp_server.py

Команда запускает сервер разработки на порту 6277 и даёт локальный адрес, который нужно открыть в браузере. Загрузится панель MCP Inspector.

Об интерфейсе

MCP Inspector активно развивается, поэтому его интерфейс может отличаться от скриншотов. Но основные возможности тестирования инструментов, ресурсов и промптов должны остаться похожими.

Подключение и проверка инструментов

Нажмите кнопку «Connect» слева, чтобы запустить MCP-сервер. После подключения появится панель с разделами Resources, Prompts, Tools и другими.

Чтобы проверить инструменты:

  • перейдите в раздел Tools;
  • нажмите «List Tools», чтобы увидеть все доступные инструменты;
  • выберите инструмент — откроется его форма проверки;
  • заполните нужные параметры;
  • нажмите «Run Tool», чтобы выполнить и увидеть результат.

Проверка операций с документами

Например, чтобы проверить инструмент чтения документа, введите ID документа (скажем, «deposition.md») и запустите инструмент. Инспектор покажет результат — возвращённое содержимое или сообщение об успехе.

Операции можно выстраивать в цепочку. Например, после правки документа заменой текста сразу снова запустите инструмент чтения и убедитесь, что изменения применились.

Цикл разработки

Инспектор даёт эффективный цикл разработки:

  • вносите изменения в код MCP-сервера;
  • проверяете отдельные инструменты в инспекторе;
  • проверяете результаты без полного приложения;
  • отлаживаете проблемы изолированно.

Инспектор становится незаменим, когда серверы усложняются. Не нужно подключать сервер к Claude или другому приложению ради проверки базовой функциональности — разработка идёт быстрее и сосредоточеннее.

Пояснение

  • Команда. mcp dev — часть CLI Python SDK (ставится с дополнением mcp[cli]). С UV удобнее uv run mcp dev mcp_server.py — тогда не нужно отдельно активировать окружение. В SDK 2.x команда сохранилась.
  • Инспектор проверяет сервер, а не модель. Он отвечает на вопрос «правильно ли сервер выполняет инструменты», но не «правильно ли Claude их выбирает». Второе проверяют уже в приложении — оценкой, как в блоке «Оценка промптов».
