Упражнение: чистые команды

Чему научитесь

Около 5 минут

На странице нет текста, только ролик. Задача из него такая.

Смотреть урок на Skilljar Structured data exercise · 4:57

Что просят

Промпт уже задан: сгенерировать три разных примера команд AWS CLI. Его менять нельзя. Без prefill и stop sequence ответ — три команды плюс заголовок и нумерация.

Нужно получить те же три команды подряд, без комментариев и пояснений. Разрешены только prefill сообщения assistant и stop sequences.

Как идёт решение в ролике

  1. Смотрят сырой ответ: каждая команда уже обёрнута в три обратные кавычки.
  2. В prefill кладут эти три кавычки, в stop sequence — закрывающие три кавычки.
  3. Команды появляются, но в начале остаётся слово bash: так Claude помечает язык markdown-блока.
  4. Слово bash дописывают в prefill сами, чтобы модель не вставляла его ещё раз и поняла, что внутри блока команды bash.
  5. Этого мало: иногда приходит одна команда, иногда внутри блока появляются комментарии bash.
  6. В prefill добавляют фразу, которая задаёт форму ответа. В ролике это: «Here are all three commands in a single block without any comments», двоеточие и перевод строки, и уже потом кавычки блока.
add_user_message(messages, "Generate three different sample AWS CLI commands")
add_assistant_message(
    messages,
    "Here are all three commands in a single block without any comments:\n```bash"
)
text = chat(messages, stop_sequences=["```"])

Пояснение

Prefill не обязан быть только кавычками. Ролик отдельно это подчёркивает: в начало ответа можно положить любую фразу, и модель продолжает с этого места. Промпт пользователя при этом не трогают.

Дальше
