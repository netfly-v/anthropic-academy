Лишний текст вокруг данных

Видео и код урока.

Смотреть урок на Skilljar Structured data

Если просить JSON, код Python или список, Claude часто добавляет пояснение. Урок берёт веб-приложение, которое генерирует правила AWS EventBridge: пользователь вводит описание, жмёт кнопку и хочет скопировать чистый JSON. Обёртка этому мешает.

Что приходит по умолчанию

JSON верный, но он внутри markdown и рядом есть комментарий. Для кнопки «скопировать» это лишнее.

```json
{
  "source": ["aws.ec2"],
  "detail-type": ["EC2 Instance State-change Notification"],
  "detail": {
    "state": ["running"]
  }
}
```

This rule captures EC2 instance state changes when instances start running.

Prefill и stop sequence

Урок совмещает два приёма. В историю кладут сообщение пользователя и уже начатое сообщение assistant. Генерацию обрывают на закрывающих кавычках блока.

messages = []

add_user_message(messages, "Generate a very short event bridge rule as json")
add_assistant_message(messages, "```json")

text = chat(messages, stop_sequences=["```"])
  • user говорит, что генерировать;
  • prefill ```json выглядит так, будто блок кода уже открыт;
  • Claude продолжает самим JSON;
  • когда он пытается закрыть блок тремя обратными кавычками, stop sequence останавливает генерацию.

На выходе остаётся JSON без обёртки:

{
  "source": ["aws.ec2"],
  "detail-type": ["EC2 Instance State-change Notification"],
  "detail": {
    "state": ["running"]
  }
}

Разобрать строку

Лишние переводы строк снимают перед разбором.

import json

# Clean up and parse the JSON
clean_json = json.loads(text.strip())

Не только JSON

Тот же приём годится везде, где нужен кусок без комментария: фрагмент Python, список, CSV, любой формат, который модель хочет обернуть. Смотрят, во что она оборачивает ответ сама, и это делают prefill и stop sequence. Для кода это обычно markdown-блок. Для списка граница другая.

Пояснение

Функция chat из прошлых уроков принимала messages, потом system и temperature. В этом вызове у неё ещё аргумент stop_sequences: его нужно прокинуть в messages.create так же, как temperature. Иначе пример урока не с чем вызвать.
