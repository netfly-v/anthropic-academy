Что такое субагенты

Чему научитесь

Видео 2:46 и текст урока

К концу урока вы сможете:

  • объяснить, что такое субагент и зачем ему собственное окно контекста;
  • описать, что субагент получает на старте и что возвращает в основной разговор;
  • назвать встроенных субагентов Claude Code и задачи каждого;
  • оценить, чем приходится платить за чистый основной контекст.

Видео и текст урока.

Субагенты — это специализированные ассистенты, которым Claude Code может передавать задачи. Считайте их помощниками, сосредоточенными на своём деле: каждый работает в собственном окне контекста, делает свою работу и возвращает краткий итог в основной поток. Промежуточные шаги — каждое чтение файла, каждый поиск и вызов инструмента — остаются изолированными и никогда не засоряют ваш основной разговор.

Почему субагенты важны

Каждый раз, когда вы общаетесь с Claude Code, вы пополняете основное окно контекста. Каждый вызов инструмента, каждый прочитанный файл, каждый результат поиска сохраняются там. Это пространство ограничено, и когда оно заполняется, Claude начинает упускать из виду более ранние части разговора.

Субагенты решают эту проблему: для них открывается отдельное окно контекста. В стартовый контекст субагента входят:

  • собственный системный промпт из вашего файла конфигурации — он задаёт роль и поведение субагента;
  • описание задачи, которое родительский агент составляет на основе вашей просьбы.

Дальше субагент работает самостоятельно. Он читает файлы, выполняет поиск, правит код — делает всё, что нужно. Когда он заканчивает, в основной разговор возвращается только краткий итог. Остальную часть разговора субагента Claude Code сохраняет в отдельный файл транскрипта.

Благодаря этому основной контекст остаётся чистым. Вы получаете ответ без всего шума, которым сопровождался его поиск. Цена такого подхода в том, что основной разговор не видит, как субагент пришёл к своим выводам.

Пояснение

  • Видео и текст расходятся. В видео сказано, что по завершении работы разговор субагента полностью отбрасывается. Верен текст урока: по документации (на ноябрь 2026) транскрипт субагента хранится в отдельном файле agent-{agentId}.jsonl, не затрагивается при сжатии основного разговора, а работу субагента можно продолжить с полной историей.
  • Что ещё есть на старте. Кроме системного промпта и задачи, субагент по умолчанию получает те же файлы CLAUDE.md, что и основной разговор; встроенные Explore и Plan их пропускают. Историю вашего разговора обычный субагент не видит, поэтому всё нужное должно быть в описании задачи. Исключение — форк: он наследует весь разговор.

Практический пример

Допустим, вы разбираетесь в незнакомой кодовой базе и хотите узнать, какой сервис обрабатывает возвраты платежей. Без субагента Claude может прочитать 15 файлов, несколько раз выполнить поиск и пройти по цепочке из нескольких вызовов функций. Всё это заполняет окно контекста, хотя вам нужен был всего один факт.

С субагентом всё гораздо чище. Вы задаёте вопрос — запускается субагент Explore, который проделывает все эти раскопки в собственном контексте и возвращает ответ по существу.

В основном окне контекста остаются только вопрос и краткий итог, а не 15 файлов, прочитанных по пути.

Встроенные субагенты

В Claude Code уже есть несколько встроенных субагентов, которыми можно пользоваться сразу:

  • субагент общего назначения (general purpose) — для многошаговых задач, где нужно и исследовать, и действовать;
  • Explore — для быстрого поиска по кодовой базе и навигации по ней;
  • Plan — используется в plan mode, чтобы исследовать и проанализировать вашу кодовую базу, прежде чем представить план.

Пояснение

Системный промпт встроенных субагентов задан самим Claude Code, а файл конфигурации нужен только вашим собственным. По документации (на ноябрь 2026) Explore и Plan только читают: инструменты Write и Edit им запрещены. Субагенту общего назначения (general-purpose) доступен весь набор инструментов для субагентов, включая правку файлов.

Собственные субагенты

Помимо встроенных вариантов, можно создавать собственных субагентов со своими системными промптами и доступом к инструментам. Так можно описать специализированных агентов под свой рабочий процесс — рецензента кода, автора тестов, генератора документации или любого другого, кто вам нужен.

Главное

Субагенты дают три основных преимущества:

  • они разбивают работу на чётко очерченные части, и каждый субагент сосредоточен на своей конкретной задаче;
  • они держат основное окно контекста чистым, изолируя всю промежуточную работу;
  • они возвращают только нужную вам информацию — в виде сжатого итога.

Пользуетесь ли вы встроенными или создаёте своих, субагенты остаются практичным способом извлечь больше пользы из долгих сессий Claude Code. Чем меньше шума в основном контексте, тем дольше и эффективнее можно работать.
