# Anthropic Academy — русский учебный сайт

Владелец проходит курсы Anthropic Academy (Skilljar), чтобы сдать экзамен на сертификат Claude. Этот репозиторий — статический сайт с русским конспектом курсов: переводы уроков, пояснения, пробные экзамены.

- Сайт: https://netfly-v.github.io/anthropic-academy/ (GitHub Pages из `main`, корень). **Push в `main` = деплой.** Всё, что лежит в репозитории, публикуется.
- Репозиторий: `netfly-v/anthropic-academy`, remote `origin` через ssh-алиас `github-my`.
- Общение с владельцем — по-русски.

## Структура

```
index.html                 каталог курсов
<курс>/index.html          обзор курса
<курс>/quiz.html           пробный экзамен
<курс>/lessons/NN-*.html   уроки
css/style.css              общие стили
js/quiz.js                 движок экзаменов; js/<курс>-quiz.js — банки вопросов (window.QUIZ_BANK)
js/sidebar.js              прокручивает меню к группе текущего урока (подключён на каждой странице с меню)
assets/                    картинки из уроков (assets/api/ — курс API)
tools/skilljar/            скрипт выгрузки уроков со Skilljar
tools/site/                сборка курса API: blocks.json (блоки, уроки, экзамены) + build_api_block.py
```

Курсы: `skills/` — Introduction to agent skills; `api/` — Building with the Claude API (сделаны введение и блок «Accessing Claude with the API»).

Сборки нет: страницы — обычный HTML, открываются двойным щелчком. Для проверки: `python3 -m http.server` в корне.

## Две роли

- **Строитель** — обычная сессия Claude Code. Делает уроки, квизы, правки сайта, коммитит и пушит.
- **Репетитор** — `academy-tutor` в терминале (`claude --agent tutor --settings .claude/tutor-settings.json`). Только объясняет и тренирует, сайт не правит. Его заметки — в `.study/` (в `.gitignore`).

## Правила правки сайта (для строителя)

1. **Сначала оригинал.** Перед переводом урока выгрузить его со Skilljar (`tools/skilljar/README.md`) и работать по дампу: текст, код, картинки, субтитры видео. Никогда не писать урок по памяти или общим знаниям.
2. **Полный перевод.** Каждый абзац оригинала — естественным русским, в том же порядке разделов. Код, имена моделей и URL — как на Skilljar. Термины API (`max_tokens`, `stop_reason`, prefill…) не переводить.
3. **Пояснения.** Сложное, неочевидное или устаревшее — в блок «Пояснение» (`<aside class="callout"><p class="callout-label">Пояснение</p>…</aside>`). Актуальные факты (ID моделей, возможности API) проверять по документации, не по памяти.
4. **Картинки оригинала** — в `assets/`, на тех же местах, что в уроке: `<figure class="shot"><img …><figcaption>…</figcaption></figure>`.
5. Ссылки «Смотреть урок на Skilljar» — `target="_blank" rel="noopener noreferrer"`.
6. Квизы — на английском, в стиле сертификационного экзамена; результат только после Submit, сброс кнопкой «Очистить».
7. Шапку, сайдбар и навигацию «Назад/Дальше» менять согласованно во всех страницах курса.
8. Перед пушем: проверить, что нет битых внутренних ссылок и картинок.

## Как добавить блок курса API (для строителя)

1. Выгрузить уроки: `~/.academy-browser/venv/bin/python tools/skilljar/skilljar.py dump claude-with-the-anthropic-api --from A --to B`.
2. Картинки — в `assets/api/apiNN-KK.png` (NN — номер страницы урока на сайте), по порядку из дампа.
3. Написать фрагменты `<main>` уроков в отдельной папке (`NN.html`: h1, «Чему научитесь», перевод, «Пояснение», «Дальше») и банк экзамена `js/api-<блок>-quiz.js`.
4. Добавить блок в `tools/site/blocks.json` (уроки, экзамен, официальный квиз) и обновить `next_section`.
5. `python tools/site/build_api_block.py --frags <папка>` — создаст страницы уроков и экзамена, пересоберёт меню на всех страницах и `api/index.html`. Без `--frags` только пересобирает меню и страницу курса; существующие уроки не трогает.
