Курсы

Русские конспекты курсов Anthropic Academy: те же темы, своими словами, с пояснениями там, где оригинал короткий или уже устарел.

  • Введение в agent skillsШесть уроков готовы. Как устроены skills в Claude Code, где они лежат и как ими делиться.
  • Building with the Claude APIКурс переведён целиком: 76 уроков в девяти блоках, от доступа к API до агентов, пробные экзамены по блокам и итоговый экзамен.
  • Введение в Model Context ProtocolКурс переведён целиком: 12 уроков о своём MCP-сервере и клиенте на Python — инструменты, ресурсы, промпты и MCP Inspector, базовый и сложный пробные экзамены.
  • Claude Code in ActionКурс 2026 года переведён целиком: 9 уроков о долгих и автономных сессиях — CLAUDE.md, skills, режимы разрешений, hooks, routines, GitHub Actions и плагины, базовый и сложный пробные экзамены.
  • Введение в субагентовКурс переведён целиком: 4 урока о субагентах Claude Code — как они работают, как их создать и настроить и когда делегировать стоит, пробный экзамен.
  • Tool use в Messages APIКурс переведён целиком: 9 уроков о надёжном, быстром и дешёвом tool use — описания инструментов, strict, параллельные и потоковые вызовы, code execution, web search, computer use и цена, пробный экзамен.
  • Claude Platform 101Курс переведён целиком: 13 уроков о Claude Platform с нуля — запрос и выбор модели, цикл агента, tool use, thinking, встроенные инструменты, skills, MCP, контекст и Managed Agents, пробный экзамен.
  • Claude Code 101Курс переведён целиком: 12 уроков о повседневной работе с Claude Code — цикл Explore → Plan → Code → Commit, контекст, ревью, CLAUDE.md, субагенты, skills, MCP и hooks, пробный экзамен.
  • CCAR-F: темы вне курсовКонспект по официальной документации для экзамена Claude Certified Architect: карта всех подпунктов гайда — что покрыто курсами и куда идти — и страницы по темам, которых в курсах нет.
