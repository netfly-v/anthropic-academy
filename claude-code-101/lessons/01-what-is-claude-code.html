Что такое Claude Code

Чему научитесь

Видео 2:55 и текст урока

К концу урока вы сможете:

  • объяснить, чем Claude Code отличается от Claude.ai и почему его называют ИИ-агентом;
  • перечислить, что Claude Code делает в проекте: читает код, правит файлы, запускает команды, ищет в интернете;

Видео и текст урока.

Claude Code — агентный инструмент для программирования: он разбирается в вашей кодовой базе, правит файлы, запускает команды и встраивается в инструменты разработки, которыми вы уже пользуетесь, помогая быстрее справляться с задачами. Он доступен в терминале, в Visual Studio Code, в приложении Claude Desktop, в вебе и в IDE от JetBrains.

Чем Claude Code отличается от Claude?

Если вы уже пользовались Claude.ai, вам, наверное, интересно, чем от него отличается Claude Code. В отличие от Claude.ai, у Claude Code есть прямой доступ к вашим файлам, к терминалу и ко всей кодовой базе. Вам не нужно копировать и вставлять код туда и обратно: Claude Code сам берётся за дело прямо в проекте.

Главное отличие в том, что Claude Code работает как ИИ-агент (AI Agent).

Что такое агент?

ИИ-агент — это программа, которая может взаимодействовать со своим окружением и выполнять действия, чтобы достичь поставленной цели. В основе лежит большая языковая модель, которая работает в цикле в реальном времени. У ИИ-агентов может быть доступ к инструментам, внешним сервисам и даже другим ИИ-агентам — всё это помогает им достигать целей.

Что Claude Code умеет на самом деле?

Вот как это выглядит на практике:

  • Читает и понимает вашу кодовую базу. Можно попросить Claude Code объяснить, как устроена какая-то функциональность, или проследить ошибку по всему коду.
  • Правит файлы по всему проекту. Claude Code может отрефакторить функцию и обновить все файлы, которые на неё ссылаются.
  • Запускает команды в терминале. Он может выполнить ваш скрипт сборки, прогнать тесты, установить пакеты и по выводу команд решить, что делать дальше.
  • Ищет в интернете. Если ему нужна документация или свежий справочник по API, он может найти их за вас.

Как работать с Claude Code эффективно

Чтобы работать с Claude Code эффективно, держите в голове три понятия.

Контекстное окно. Считайте его рабочей памятью Claude. Оно вмещает много, но не всё сразу. Здесь и проявляется «агентность»: Claude продуманно ищет ответы в вашей кодовой базе, не загружая её в контекст целиком.

Разрешениями управляете вы. Режимы разрешений Claude Code позволяют выбрать, насколько активно вы участвуете в работе: Claude может спрашивать вас, прежде чем запускать команды или вносить изменения, а может работать в режиме auto: тогда вместо вопросов большинство действий проходит фоновую проверку безопасности. Контроль всегда остаётся за вами — независимо от того, участвуете ли вы в каждом шаге или предпочитаете не вмешиваться.

Он может ошибаться. Как и любой инструмент, Claude Code не идеален. Он может неверно понять, чего вы хотите, внести ошибку или переусложнить решение. Если не выпускать работу из виду, такие промахи легче поймать на ранней стадии.

Пояснение

  • Как Claude ищет ответы. Проект не загружается в контекст заранее: Claude ищет файлы по шаблону имени и по содержимому, а читает только нужные. Место в контекстном окне занимают разговор, прочитанные файлы и вывод команд.
  • Режим по умолчанию. В видео сказано, что по умолчанию Claude Code спрашивает разрешения перед командами и изменениями. По документации (на ноябрь 2026) в свежих версиях интерактивная сессия в терминале и VS Code стартует в режиме auto: модель-классификатор проверяет действия и блокирует то, что выходит за рамки вашей просьбы; вопросов меньше, но безопасность не гарантирована. Если auto недоступен, сессия стартует в режиме Manual (default): файлы проекта Claude читает без вопросов, а перед большинством правок, команд оболочки и обращений к сети спрашивает. В терминале режимы переключают клавишами Shift+Tab.

Итог

Claude Code — агентный инструмент для программирования. Он читает вашу кодовую базу, правит файлы, запускает команды и подключается к внешним инструментам, чтобы вы быстрее доводили работу до релиза. Пользоваться им можно уже сегодня: в терминале, VS Code, JetBrains и приложении Claude Desktop.
