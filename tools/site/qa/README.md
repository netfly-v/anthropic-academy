# Промпты проверки сложного банка

Контроль качества из `tools/site/hard-quiz-requirements.md` проводят субагенты по этим промптам. Пути к файлам
(экзамен, текст уроков, дамп, нумерация уроков) передаются в задании субагента.

- `dump_md.py <дамп> <папка> [--only A-B]` — `NN-<id>.md` (страница + субтитры) и `lessons-text-only.md` (без кода и видео).
- `mkblind.py js/<банк>.js <папка>` — `full.json` (с ключом и `why`) и `blind.json` (только условия и варианты).
- `QA-BLIND.md` — решатель «вслепую»: без уроков, отмечает подсказки формы.
- `QA-READER.md` — «прочитавший урок»: текст страниц уроков без кода и видео, ≥85%, основа каждого ответа.
- `QA-VERIFY.md` — придирчивая сверка ключа, дистракторов и `why` с дампом.
- `QA-TRACE.md` — аудит источника: на чём держится ключ и опровержение каждого дистрактора.
- `QA-FORM.md` — критик формы: что угадывается без знания темы.
- `TRANSLATE-WHY.md`, `TRANSLATE-STEM.md` — правила для переводчиков `why_ru` и `stem_ru` (и для их рецензентов).

Текст уроков без кода и видео (`lessons-text-only.md`) и дамп в формате `NN-<id>.md` (текст страницы, затем
«(video transcript)») собираются из `~/Projects/skilljar-dump/<курс>/`.
