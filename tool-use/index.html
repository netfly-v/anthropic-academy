Tool use в Messages API

Что делать, когда tool use уже работает: как сделать вызовы инструментов надёжными, быстрыми и дешёвыми и как подключить инструменты, которые предоставляет Anthropic.

Курс Anthropic Academy на academy.claude.com для тех, у кого первый круг tool use уже работает: Claude вызывает ваш инструмент, код его выполняет, результат возвращается. Каждый урок разбирает одну проблему на примере вымышленной инженерной фирмы Meridian. Здесь весь курс в том же порядке, что и в оригинале: текст по-русски, плюс пояснения там, где урок короткий или расходится с документацией. Видео — те же ролики с YouTube.
