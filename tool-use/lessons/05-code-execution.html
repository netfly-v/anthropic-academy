Code execution: Claude запускает код, который пишет

Чему научитесь

Видео 3:26 и текст урока

К концу урока вы сможете:

  • объяснить, чем серверный инструмент code execution отличается от ваших собственных инструментов, и подключить его одной записью в tools;
  • передать свои файлы в контейнер через Files API и блоки container_upload;
  • прочитать ответ Claude и продолжить ход, если API вернул stop_reason со значением pause_turn.

Видео и текст урока.

Code execution позволяет Claude написать код на Python, запустить его на стороне Anthropic и ответить, опираясь на то, что выведет этот код.

Демо в этом видео записано в сентябре 2026 года. В нём использовалась модель Claude Sonnet 5 (claude-sonnet-5). На более новых моделях результаты могут отличаться.

Для ответа на некоторые вопросы нужны расчёты по множеству файлов. Это работа для кода.

Возьмём Meridian — вымышленную инженерно-консалтинговую компанию. У неё 12 CSV-файлов, по одному на каждую насосную станцию, и в каждом файле — показания расхода за год. Компания хочет знать, превышала ли хоть одна станция свою проектную производительность и, если да, когда.

Такую работу Claude делает с помощью code execution. Claude получает контейнер, в котором может запускать написанный им код на Python и отвечать, опираясь на его вывод.

Добавьте инструмент в запрос

Code execution — серверный инструмент, то есть он работает на инфраструктуре Anthropic. Обработчик для него вы не пишете, и ваш код не отправляет обратно tool_result.

Чтобы подключить code execution, достаточно одной записи в списке tools. Дата в конце значения поля type этой записи — версия инструмента; Meridian использует code_execution_20260120. Актуальные версии перечислены в справочнике инструментов (Tool reference), поэтому значение type копируйте оттуда.

Meridian хранит этот список в константе TOOLS, а в запросе передаёт его как tools=TOOLS:

TOOLS = [{"type": "code_execution_20260120", "name": "code_execution"}]

На октябрь 2026 года code execution работает в Claude API, в Claude Platform on AWS, в моделях Claude в Google Cloud, которыми управляет Anthropic, и в развёртываниях Microsoft Foundry, размещённых у Anthropic.

Пояснение

  • Версии. На ноябрь 2026 актуальны три версии; code_execution_20260120 из урока — одна из них, а самая новая, code_execution_20260521, работает в той же среде.
  • Состояние Python. В видео сказано, что состояние Python сохраняется между ходами начиная с code_execution_20260120. Документация уточняет: переменные интерпретатора сохраняются между запросами, только если переиспользовать контейнер и работать с programmatic tool calling, а файлы в переиспользованном контейнере сохраняются на любой версии. Ограничение для Haiku из видео относится только к Claude Haiku 4.5.

Положите файлы в контейнер

Код Claude выполняется в контейнере на стороне Anthropic. А файлы пока лежат на вашей машине, поэтому в контейнере их ещё нет. Программа Meridian переносит их в контейнер в два шага:

  1. Загрузить каждый файл через Files API — в ответ вы получите ID файла.
  2. Указать этот ID файла в сообщении, в блоке container_upload.

Программа Meridian добавляет по одному блоку container_upload на каждый файл — в то же сообщение, где стоит её вопрос. После этого файлы загружаются в контейнер, и код Claude может их открыть.

Прочитайте ответ Claude

Ваш код отправляет один запрос и обычно получает уже готовый ответ.

API может приостановить долгий ход и вернуть stop_reason со значением pause_turn. В этом случае отправьте содержимое ответа обратно как сообщение с ролью assistant, с теми же tools, и Claude продолжит.

Ответ Claude для Meridian: станция 7 дважды превысила свою проектную производительность в 600 л/с — в апреле и мае 2025 года. В ответе API это заключение идёт после команд, которые запускал Claude.

Пояснение

По документации code execution (на ноябрь 2026), в запрос-продолжение после pause_turn нужно передать и ID контейнера из ответа — в параметре container верхнего уровня (container=resp.container.id). Без него запрос выполнится в новом контейнере, и файлы, которые уже появились в контейнере за этот ход, пропадут. Тем же параметром контейнер переиспользуют и в следующих запросах: запрос без container всегда получает новый контейнер. Продолжение тоже может вернуть pause_turn: повторяйте его, пока stop_reason не сменится, и храните в messages все приостановленные ответы по порядку. Программа ниже pause_turn не обрабатывает.

Соберите программу

Ниже — программа Meridian: она подключает инструмент, кладёт файлы в контейнер и читает ответ. В программе paths содержит 12 CSV-файлов в виде объектов pathlib.Path, а QUESTION — вопрос Meridian.

На странице урока здесь интерактивное упражнение: дан пример программы на Python, которая использует инструмент code execution, и нужно сопоставить каждую описанную задачу со строкой, которая её выполняет. При неверном выборе появляется подсказка, а при верном — короткая заметка об этом шаге.

Задание: «Выберите строку программы, которая выполняет эту задачу». Задачи идут по одной; первая из пяти: «Вы хотите, чтобы код Claude мог открыть каждый загруженный вами файл». Программа из упражнения:

TOOLS = [{"type": "code_execution_20260120", "name": "code_execution"}]

content = []
for path in paths:
    uploaded = client.files.upload(file=path)
    content.append({"type": "container_upload", "file_id": uploaded.id})
content.append({"type": "text", "text": QUESTION})
messages = [{"role": "user", "content": content}]

resp = client.messages.create(
    model="claude-sonnet-5", max_tokens=8000,
    tools=TOOLS, messages=messages,
)
print("".join(b.text for b in resp.content if b.type == "text"))

Главное

  • Code execution — серверный инструмент. Вы добавляете одну запись в tools, а код Claude выполняется в контейнере на стороне Anthropic.
  • Каждый файл вы загружаете через Files API, а затем указываете его ID в блоке container_upload.
