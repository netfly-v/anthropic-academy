Web search: ответы с сайтов, которым вы доверяете

Чему научитесь

Видео 3:57 и текст урока

К концу урока вы сможете:

  • подключить серверный инструмент веб-поиска одной записью в tools и продолжить ход после pause_turn;
  • объяснить, что даёт динамическая фильтрация и когда она включена по умолчанию;
  • ограничить поиск доверенными сайтами через allowed_domains;
  • собрать ответ из всех блоков text и вывести источники из блоков web_search_tool_result.

Видео и текст урока.

Инструмент веб-поиска (web search) позволяет Claude искать в интернете, пока он работает над вашим запросом. Динамическая фильтрация (dynamic filtering) оставляет только нужные части результатов поиска, поэтому на запросы, где много поиска, уходит меньше токенов. Meridian, вымышленная инженерная консалтинговая компания, ссылается в своих предложениях для клиентов на инженерные стандарты.

Демо в этом видео записано в сентябре 2026 года. Оно работало на Claude Sonnet 5 (claude-sonnet-5). На более новых моделях результаты могут отличаться.

Claude отвечает на основе того, что узнал при обучении, поэтому не знает ни о чём, что появилось позже, и ни о чём, чего в обучающих данных не было. Когда для ответа нужны такие факты, их кому-то приходится искать, и эта рутина достаётся вам.

С инструментом веб-поиска Claude делает эту работу сам: ищет в интернете, пока работает над вашим запросом, и отвечает по тому, что нашёл.

Одно из предложений Meridian ссылается на четыре канадских инженерных стандарта с точностью до пункта, и если хоть одна ссылка неверна, Meridian несёт профессиональную ответственность. Поэтому, прежде чем отправить предложение, Meridian хочет сверить каждую ссылку с официальными источниками.

Добавьте инструмент в запрос

Веб-поиск — серверный инструмент. Он работает на инфраструктуре Anthropic, поэтому писать для него обработчик и отправлять обратно tool_result не нужно.

Чтобы его подключить, достаточно одной записи в списке tools. Поле type этой записи задаёт версию инструмента, и Meridian указывает web_search_20260209. Поле name всегда равно web_search. Действующие версии перечислены в справочнике инструментов, так что значение type копируйте оттуда.

На моделях Claude 4.6 и новее версии начиная с web_search_20260209 по умолчанию используют динамическую фильтрацию. Claude запускает код, который фильтрует результаты поиска, поэтому в контекстное окно попадает только нужное.

Обычно Claude выполняет весь поиск в рамках одного запроса. Ваш код отправляет этот запрос и получает готовый ответ.

API может приостановить долгий ход и вернуть stop_reason со значением pause_turn. Тогда отправьте содержимое ответа обратно как сообщение ассистента, с теми же tools, и Claude продолжит.

Каждый поиск оплачивается сверх стоимости токенов. Веб-поиск есть не на каждой облачной платформе.

Пояснение

  • Версии. На ноябрь 2026 действуют три: web_search_20250305 (базовая), web_search_20260209 (добавляет динамическую фильтрацию) и web_search_20260318 (ещё и параметр response_inclusion).
  • Как работает фильтрация. Поиск идёт изнутри code execution: у этих версий allowed_callers по умолчанию — ["code_execution_20260120"], а контейнер выделяет сам API. На моделях без programmatic tool calling, как сказано в видео, нужно указать "allowed_callers": ["direct"], иначе API вернёт 400.
  • Облака. На ноябрь 2026, как и в видео: на Amazon Bedrock веб-поиска нет; в Claude Models on Google Cloud (Google managed) — только базовая версия; в Claude Platform on AWS и Google Cloud под управлением Anthropic — все версии.

Укажите, какими сайтами Claude может пользоваться

Пока в запросе ничто не ограничивает, на каких сайтах Claude может искать, и для Meridian это проблема. В открытом интернете полно постов на форумах и сайтов перепродавцов, а Meridian может ручаться только за официальные источники.

Поэтому вы указываете поиску, где искать. allowed_domains — ещё одно поле в записи инструмента, и оно ограничивает результаты поиска сайтами, которые вы перечислили. Meridian называет четыре сайта. Два принадлежат организациям, которые издают эти стандарты и сертифицируют на соответствие им, — csagroup.org и cwbgroup.org. Два — государственные: ontario.ca и canada.ca.

allowed_domains принимает список. В каждом элементе пишите только домен, без https://; его поддомены тоже будут разрешены.

Прочитайте ответ и его источники

Ответ Claude может прийти несколькими блоками text, между которыми идут поиски. Поэтому, чтобы получить ответ целиком, склейте все блоки text.

Кроме того, каждый поиск добавляет в ответ блок web_search_tool_result. В нём лежит список результатов, которые вернул поиск, и у каждого результата есть title и url.

Из четырёх ссылок Meridian, как выяснил Claude, две верны, третья верна во всём, кроме номера подпункта, а четвёртая ошибочна.

Соберите программу

Программа Meridian объединяет эти шаги. В ней excerpt хранит отрывок из предложения, а QUESTION — вопрос Meridian.

На странице урока здесь интерактивное упражнение: дана программа на Python с инструментом веб-поиска, и для каждой из пяти задач — например, ограничить результаты перечисленными доменами или выбрать версию инструмента — нужно указать строку, которая её выполняет. При неверном выборе появляется подсказка, а при верном — короткая заметка об этой строке.

Задание: «Выберите строку программы, которая выполняет эту задачу». Задача 1 из 5: ответ Claude приходит несколькими частями, между которыми идут поиски, и вы хотите прочитать его целиком.

TOOLS = [{
    "type": "web_search_20260209",
    "name": "web_search",
    "allowed_domains": ["csagroup.org", "cwbgroup.org",
                        "ontario.ca", "canada.ca"],
}]

def answer(resp):
    return "".join(b.text for b in resp.content if b.type == "text")

messages = [{"role": "user", "content": QUESTION + excerpt}]
resp = client.messages.create(
    model="claude-sonnet-5", max_tokens=4096,
    tools=TOOLS, messages=messages,
)
print(answer(resp))

for block in resp.content:
    if block.type == "web_search_tool_result":
        if isinstance(block.content, list):
            for result in block.content:
                print(result.title, result.url)

Пояснение

  • Домены. На ноябрь 2026 есть и обратный список blocked_domains, но в одном запросе допустимо только одно из двух полей, иначе API вернёт 400. В элементе можно указать и путь (example.com/blog), а поддомен (docs.example.com) ограничивает поиск только им.
  • Зачем isinstance. Если поиск не удался (например, max_uses_exceeded), статус ответа всё равно 200, но content блока web_search_tool_result — не список, а объект web_search_tool_result_error с error_code. Поиск без результатов даёт пустой список.
  • Цитаты. У веб-поиска они включены всегда: у блоков text, основанных на найденном, есть поле citations с url, title и cited_text.

Главное

  • Веб-поиск — серверный инструмент: вы добавляете одну запись в tools и не пишете обработчик. Обычно Claude выполняет весь поиск в рамках одного запроса.
  • allowed_domains ограничивает результаты поиска сайтами, которые вы назвали.
  • На моделях Claude 4.6 и новее в web_search_20260209 и более поздних версиях динамическая фильтрация включена по умолчанию, поэтому в контекстное окно попадает только нужное.
