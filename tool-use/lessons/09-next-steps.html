Чему научитесь

Текстовый урок, около 2 минут

К концу урока вы сможете:

  • вспомнить, как курс предлагает бороться с неверными вызовами инструментов, долгим ожиданием и высокой ценой запросов и когда подключать инструменты Anthropic;
  • решить, с какой проблемы начинать в собственном коде;
  • знать, где искать дальше: руководство Troubleshooting tool use, справочник инструментов, Claude Cookbook и курс по MCP.

На странице урока нет видео, только текст.

Теперь вы можете разобрать проблему агента, который пользуется инструментами, и выбрать подходящее для неё исправление. Коротко вспомним, что было в курсе.

Что вы теперь умеете

  • Добиваться правильных вызовов инструментов. Описывайте, когда вызывать каждый инструмент, а когда нет, проверяйте правки оценкой (eval) и включайте strict tool use.
  • Сокращать ожидание и показывать, что происходит. Запускайте независимые вызовы инструментов параллельно и включайте потоковую передачу, чтобы пользователи, пока ждут, видели, какой инструмент выбрал Claude.
  • Пользоваться инструментами, которые предоставляет Anthropic. Добавляйте code execution и web search — они выполняются на стороне Anthropic, — а computer use оставляйте для программ, к которым нет другого доступа.
  • Тратить меньше. Измеряйте входные токены каждого запроса, кешируйте определения инструментов и применяйте programmatic tool calling.

Пояснение

В справочнике Tool reference (на ноябрь 2026) инструменты Anthropic делятся на два вида. Серверные (server tools) выполняются на инфраструктуре Anthropic: обработчик писать не нужно. У клиентских (client tools) Anthropic задаёт только схему, а каждый вызов выполняет ваша программа. Из трёх инструментов курса code execution и web search — серверные, а computer use — клиентский, поэтому скриншоты, клики и ввод текста делает ваш код.

Назад к своему коду

Вернитесь к своему коду и начните с той проблемы, которая сильнее всего мешает вам или вашим пользователям. Примените исправление из урока, который посвящён именно ей. Уроки никуда не денутся, так что любой из них можно снова открыть прямо во время работы.
